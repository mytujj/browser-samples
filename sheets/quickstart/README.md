# CEO Command App
A Flutter-based operational system to manage creative & business workflows for music industry professionals. Includes dashboards, SOP tracking, and KPI monitoring.

## Prerequisites
1. Google Cloud project with the Sheets API enabled
2. OAuth 2.0 client credentials
3. Flutter SDK installed

## Getting Started
1. Clone this repository
2. Run `flutter pub get` to install dependencies
3. Run `flutter run` to launch the application

## Setup Google Sheets Access
1. Complete the [Google Sheets API Quickstart](https://developers.google.com/sheets/api/quickstart/javascript) setup
2. Configure your OAuth 2.0 credentials
3. Update the credentials in your application

## Running Locally
Start a local development server:
```shell
python3 -m http.server 8000
```

Access the application:
```shell
open http://localhost:8000
```
